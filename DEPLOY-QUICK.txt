================================================================================
  FIREBASE HOSTING + API ON YOUR PC (RetailFlow) — MINIMUM STEPS
================================================================================

No Render required. The hosted site needs a public HTTPS URL → your laptop API (tunnel).

1) BACKEND + TUNNEL (your Mac, two terminals)
   Terminal A:  npm run backend:dev          (API on port 3001)
   Terminal B:  npm run tunnel:write          (writes frontend/.env.production)

2) backend/.env on your Mac must include:
   FRONTEND_ORIGIN=https://YOUR-PROJECT.web.app,https://YOUR-PROJECT.firebaseapp.com

3) DEPLOY STATIC SITE
   From repo root:
   npm install
   npm run deploy:hosting
   (or: npm run build && firebase deploy --only hosting)

4) Whenever you open the .web.app site: keep Terminal A + B running.
   If you restart the tunnel, run tunnel:write again, then deploy:hosting again.

5) Local-only (no Firebase): npm run dev → http://localhost:5173

================================================================================
  Optional: API on Render again
================================================================================
  Fix frontend/.env.production to your https://….onrender.com/api and remove
  the onrender check from frontend/vite.config.js if you fork it.
